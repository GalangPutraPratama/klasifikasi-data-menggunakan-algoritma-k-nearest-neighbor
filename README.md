# Klasifikasi Iris dengan K-Nearest Neighbor (KNN)

Proyek ini merupakan tugas mata kuliah **Pengantar Data Science** yang menerapkan metode CRISP-DM pada Supervised Learning untuk klasifikasi data menggunakan algoritma K-Nearest Neighbor.

## Dataset

Dataset Iris dari UCI Machine Learning Repository (150 data, 4 fitur, 3 kelas).
Dataset dimuat langsung dari library scikit-learn menggunakan `load_iris()`.

Link dataset: https://archive.ics.uci.edu/dataset/53/iris

## Teknologi

- Python 3
- scikit-learn
- Google Colab

## Cara Menjalankan

1. Buka file `knn_iris.ipynb` di Google Colab
2. Jalankan seluruh cell dari atas ke bawah
